# P3 通用信息集搜索

## 接口与算法

- [ExtremeSearch.cs](../src/ExtremeSearch.cs) 提供可信对局适配入口 ExtremeSearch.Choose 和脱敏入口 ExtremeSearch.Search。输入授权构筑后走 P2。对手构筑为 null 时使用未知构筑先验。输出 SearchAction 可交回引擎执行，包含普通动作或决策 ID 与选项 ID。执行时仍走引擎合法性校验。
- [SearchPolicy.cs](../src/SearchPolicy.cs) 提供随机合法策略、职业无关启发式策略和有界局面估值。估值使用生命、护甲、场面、资源、武器、关键词和可见斩杀压力。换边是合法动作，整条模拟另外受动作和换边上限约束。
- 每次迭代抽一个新的 P2 世界，并使用单独的规则 RNG 和策略 RNG。同一次搜索的全部迭代共用一棵根观察树。节点沿父路径、当前行动席位和根玩家可见结果组织，不以权威状态或对手隐藏身份作为哈希。
- 动作键包含操作种类、手牌或场上位置与卡牌、目标席位及位置、站位和抉择。每个采样世界重新把键映射到合法动作及实例 ID。归并仅消除结构键完全相同的重复项，保留同名牌的不同实例、不同目标和站位。
- 根玩家的选择使用根视角 Q + C√(ln A / (1+N))。A 仅在动作出现在该次采样的合法列表时增加，访问及累计收益仅沿实际走过的边更新。可选渐进扩展限制每个节点先探索多少动作，并随访问增长。继续同一回合时收益视角保持不变。
- 对手用自身视角的通用策略回应，策略只接收本席位的手牌、奥秘、合法动作和公开场面，省略牌库组成。树以公开回应边保存结果，普通出牌记录可公开身份，奥秘保持匿名，追踪选项保持私有。对手决策不使用以根私牌为条件的 UCT 统计。引擎内部自行执行抽牌、奥秘、随机伤害及随机生成。
- 己方已知的待决策候选逐项提交，可继续搜索连续发现。对手私有决策在读取候选前截断，并计入受限次数。胜负平回传 1、0、0.5。截断使用确定的近似估值。RootActionStatistics 分别返回终局胜负平与估值样本数、估值平均值。MeanValue 是两类样本的混合值。

## 预算与失败处理

固定迭代模式设置 MaxIterations。时间模式同时设置 TimeLimitMilliseconds 和迭代上限。两种模式均限制树深、模拟动作数、换边数、节点数和采样次数。采样失败重试有总上限与连续失败上限。搜索前即可确定的信念拒绝计入回退原因，不当作一次实际采样。取消、超时和节点上限保留已完成统计，统计为空时从真实合法动作使用通用优先级回退。时间是协作式预算，单次采样、观察或规则动作可能越过截止时间。

## 对战方法

纯规则引擎对战。每组均使用镜像构筑，Extreme 固定席位 0，先手按局交替。旧 AI 使用原有换牌，Extreme 与通用基线保留初始手牌。胜率是已结束对局中的胜局比例，区间使用 Wilson 95%。受限比例按所有 Extreme 决策计，包含采样前触发的 P2 回退。采样失败率只按实际调用计。每局执行超过 900 步则另记为截断，不计为平局。


每对手 500 局的正式评估可把 GAMES 设为 500，并锁定新的种子区间和预算。只测对战可将 TOUCHFISH_SEARCH_SKIP_PERF 设为 1。默认的三次性能测量会额外覆盖 100、500、2,000、5,000 档。

本实现属于单观察者、固定对手策略的 ISMCTS。仍有策略融合、非局部性及对手知识近似问题。它使用动作路径和根观察的有限公开投影，未实现多观察者树或对手后验更新。短期估值使用通用资源和场面特征，遇到 P2 不能可靠采样的场景时会合法回退。

P4 可在可信控制层捕获根观察和 P2 构造器，用可取消后台工作执行搜索。回主线程应用动作前应检查对局标识、回合、当前状态版本及决策 ID。显示时应分别读取终局胜负平、估值样本及受限比例，样本不足、动作未访问或已回退时显示相应状态。只有经过独立校准的指标才适合展示为胜率。
