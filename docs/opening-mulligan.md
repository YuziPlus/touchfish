# Extreme 通用换牌

## 决策方式

调用 ExtremeSearch.ChooseMulligan，提供合法己方构筑、可选的授权敌方构筑以及独立种子。先手枚举 8 个合法子集，后手枚举 16 个。默认采样 32 个 P2 起手世界，同一世界的各候选从同一个快照 Fork，调用真实 Mulligan，再以通用策略模拟至第 6 个席位回合或 28 次操作。候选依据实际终局或早期局面估值、各回合结束时的估值及出牌次数排序。各候选使用同一批成功世界。对手换牌模型采用通用费用曲线。

DeterminizationBuilder.CaptureOpening 仅在双方都未确认时可用。只复制己方合法手牌，双边牌库和对手手牌由 P2 先验及合法历史采样。正式对局的牌库、对手隐藏信息和真实随机数进度不参与候选计算。对局控制器应在任一方确认之前调用或捕获所需的起手信息。对手已经确认时，当前 P2 无法按对方未知换牌策略恢复其手牌后验，使用带诊断的通用费用曲线回退。取消或无可用样本也有相同类型的显式回退。全留可以作为搜索结果之一。

## 基准协议

- 公平对照双方使用同一个 OpeningMulligan.Curve，再分别由 ISMCTS 和旧动物园决定回合内操作。
- 换牌搜索组使用上述独立换牌搜索，旧动物园使用原有策略。旧冰法和旧奇迹贼的既有对战也确有不对称换牌。原工具让 Extreme 全留，两个对手均执行各自的 Mulligan。现行默认工具改为让 Extreme 进行通用搜索。
- 两个协议均使用同一镜像动物园牌表，100 和 1,000 两档，每档使用种子 952001–952100，交替先手。两种协议会同时改变一方或双方的换牌方式，比较时应保留这一实验区别。
- 逐局输出包括双方换牌张数、换前与换后费用、先后手、胜负，以及换牌搜索成功采样数和回退原因。换后费用不计幸运币和首回合抽牌。

## 验证

Extreme 专项 39 项，包含合法子集、已知与未知敌方构筑、对手隐藏信息置换、己方未公开牌库顺序置换、原局和原 RNG 隔离、已确认对手的明确回退。相关规则共 29,709 项通过。修改只涉及起手采样、决策和验证工具。

运行镜像验证入口前，先用 scripts/test.ps1 -Scope extreme-search 编译。设置 TOUCHFISH_ZOO_OPENING 为 fair 或 search，设置 TOUCHFISH_SEARCH_GAMES、TOUCHFISH_SEARCH_SEED_START、TOUCHFISH_SEARCH_MATCH_BUDGETS，然后调用 work/test-bin/Touchfish.RuleTests.exe，参数依次为仓库路径与 zoo-budget-match。该入口输出 OPENING、MULLIGAN 和 ZOO 逐局记录。
