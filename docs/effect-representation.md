# P5.3.3 卡牌效果表示

## 实现

观察 schema 3 在 schema 1 后追加 24 个可见卡槽，每槽 25 项。候选动作增加对应己方出牌来源的同一效果向量。结构化程序由 MatchRules 注册并实际执行，金额与执行逻辑共用同一份指令。覆盖基础单目标伤害及附带冻结、指定抽牌、治疗、回手、镜像召唤。金额为基础值，不预先计算法强、替代治疗、触发、护甲或未来目标。程序已知标志区分未结构化规则，后者仍按原逻辑结算。战吼、亡语、连击取自卡库标签；事件时机取自 ConditionalTrigger 定义。例如北郡牧师响应随从治疗，光明之泉在回合开始检查；不推断任意委托的条件细节。复杂效果、随机分支及衍生物属性尚未通用结构化。

只查询观察中的己方手牌及公开战场牌 ID。替换对手隐藏手牌通过不变性检查。原生模型加载支持 schema 1/2/3，schema 3 使用 893 维观察及 88 维动作。现有 PUCT 仅使用 schema 1，传入 schema 3 会走原 UCT。生产默认未切换。Python 训练使用 C# 输出的特征，导出权重在 C# 复算 logits，误差低于 2e-5。

## 规则实验

每个任务 16 个训练变体、8 个留出变体。训练用寒冰箭配圣光术或奥术智慧，留出换为火球术配治疗之触或疾跑，并交换手牌位置。抽牌任务通过正式抽牌拿到当回合不可用的随从。两组有完全相同维度及 32 个隐层单元、相同旧模型初始权重、三个采样种子、每种子 1,200 局短轨迹，学习率 .0002、PPO 批次 32。对照新增输入为零。双方随更新独立采样，局数一致。每个动作在 MatchEngine 分支中实际执行；对手用经引擎验证的一步致死回复。训练只有终局奖励，留出胜率是对整棵有限规则树按采样策略积分的精确期望。

| 任务 | 初始 | 旧表示 | 效果表示 | 每种子墙钟 旧 / 新 |
|---|---:|---:|---:|---:|
| 伤害与治疗 | 15.04% | 16.64% | 17.33% | 1.17 / 0.72 s |
| 伤害与抽牌 | 22.84% | 26.32% | 27.13% | 0.63 / 0.61 s |

墙钟含采样、训练及评测，固定顺序运行，第一组可能包含库预热。三个种子均有小幅正差，但同类留出有限、最终胜率低。两个任务只要求识别能立即获胜的伤害动作，尚未检验网络能否主动选择恰当时机抽牌、治疗、冻结、回手或召唤。当前不启动整局训练。
