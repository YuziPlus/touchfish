# 地精大战侏儒：中立牌 v0.8.5

本轮完成新增中立 **51/51** 张及10张辅助牌。本批发布为v0.8.5。

## 范围与卡池

- 新中立使用2014年12月首发数值，经典382张与纳克412张的冻结卡包不改写。本轮没有移植旧卡在2014年9月至12月间的平衡调整。
- 当前开放环境463张：经典＋纳克＋51张GVG中立。组牌按版本查看，竞技与现开读取同一开放环境。
- GVG职业新牌不在本轮范围内；因此这是中立开发阶段，并非完整的2014年12月全卡环境。
- 随机召唤、变形、机械生成和随机武器均使用 **该局所属的已开放卡池**，不生成未开放的GVG职业牌；后续职业牌加入后自动扩展。辅助牌不参与随机收集牌池。
- 旧卡组只在对战入口提升到兼容环境，原卡组记录、代码、草稿与设置不因测试改写。

## 公共机制

- `GvgRules`：卡牌注册、条件触发、战吼与零件。注册采用明确ID白名单，未来卡牌不会自动被当作已实现。
- `CardPoolId` 与 `GenerationPool()`：对局所属卡池及可生成牌集合，明确写入公共联机快照。
- `MinionAttackLimit()`：普通、风怒、超级风怒统一攻击次数入口，也用于冻结与AI观察。
- 攻击改向在公开攻击事件之前确定真实目标；死神4000型读取改向/奥秘后的相邻目标并同批伤害。
- `MinionPlayed`：仅从手牌使用随从时，在战吼/出牌奥秘前通知原有监听者，用于大胖；不响应直接召唤。
- `PaidCost`：施法触发明确收到实际支付费用，用于加兹鲁维；无需解析日志或事后反算法力。
- 亡语接入原死亡批次、死亡位置、瑞文戴尔翻倍、沉默与七槽限制。
- 米米尔隆按回合开始快照消灭己方全部存活机械，结算亡语后尝试在空位召唤V-07-TR-0N。
- 科赞以私有结构化事件交接奥秘身份；对手仅收到数量，提示不会误写成科学家。
- 魔能机甲使用独立RemovedFromDeck墓地原因，不当作抽牌、疲劳或随从死亡。

## 验证

- 新卡规则专项179项：51张逐张通过实际出牌入口，其余覆盖战吼、触发、亡语、零件、减费、攻击和卡池兼容。
- GVG WPF八项固定尺寸、版本筛选与搜索通过；双端本机回环TCP覆盖砰砰站位、机械费用、科赞私密奥秘、零件手牌和超级风怒四次攻击。
- 关联猎人、引擎、死亡队列、目标、隐私、纳克、竞技等范围检查按实际改动运行；未重跑整个旧模块全集。
- 上述为自动规则、真实WPF渲染和本机TCP验证，不代表人工鼠标操作或两台电脑实战。
