# P1 无界面模拟基准

## 环境与复现

2026-11-11，Windows 10.0.26200，Intel Core i7-13620H，64 位 .NET Framework 4.8.09221。使用现有规则测试脚本的优化编译，单线程执行。计时前预热，并执行 GC；表中只计量测量窗口内的分配和回收。

```powershell
$env:TOUCHFISH_SIMULATION_BENCHMARK = '1'
.\scripts\test.ps1 -Scope simulation
Remove-Item Env:TOUCHFISH_SIMULATION_BENCHMARK
```

分配量通过 AppDomain 的累计分配字节差得到，GC 通过各代累计回收次数差得到。结果包含该负载下的引擎和观察构建分配，可随场面、CPU 调度和 GC 波动。

- 捕获、分支复制和三步模拟使用双边各五张手牌、五个带附加属性随从的场面。捕获还复制卡库与规则定义。三步模拟从快照复制一次，再打出火球术并连续结束两次回合。
- 完整对局从法师与盗贼的基础练习卡组开局，模拟双边换牌。每步从公开观察生成合法操作，按固定优先级出牌、攻击或结束回合，直至胜负确定。平均 59.5 步，不含换牌。这是吞吐量基准。
- 快照在规则结算完成时捕获，包括实例编号、牌库顺序、手牌、奥秘、墓地、附加效果、延迟回手和随机数状态。分支各自拥有可变对局状态。分支内部共享与正式对局隔离的只读规则定义及不可变墓地条目。
- 模拟复用正式规则。无界面模式跳过视觉事件和动画等待，诺兹多姆计时由调用方显式推进。正在结算的炎爆术、局域网脱敏副本和包含自定义结算回调的对局会被拒绝捕获。快照包含权威私有状态，应留在可信进程内。策略通过按席位构建的观察读取信息。
